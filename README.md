# سایت عمومی حضوریار

صفحهٔ معرفی، بلاگ و فرم درخواست تماس. پروژه‌ای مستقل از پنل‌ها است و فقط از API عمومی
بک‌اند حضوریار استفاده می‌کند.

```bash
npm install
npm run dev        # http://localhost:3003
npm run build      # خروجی استاتیک در out/
```

برای دیپلوی، محتوای `out/` را روی هاست IIS بگذارید. تنظیمات بدون نیاز به بیلد در
`public/config.js` (و پس از دیپلوی در `config.js` روی سرور) است: آدرس API، آدرس اپ اصلی و شمارهٔ پشتیبانی.

دامنهٔ این سایت باید در `Cors:AllowedOrigins` فایل `appsettings.Production.json` بک‌اند باشد،
وگرنه فرم تماس و بلاگ کار نمی‌کنند.

## تنظیمات فروش و سئو

- `public/config.js`: شمارهٔ پشتیبانی (`__SUPPORT_PHONE__`) تنها منبع شماره در کل سایت است؛ `__WHATSAPP__` را پر کنید تا دکمهٔ واتساپ شناور ظاهر شود.
- `NEXT_PUBLIC_SITE_URL`: دامنهٔ نهایی این سایت هنگام بیلد (برای canonical، sitemap و داده‌های ساختاری).
- `lib/plans.ts`: قیمت و امکانات پلن‌ها (تعرفه، ماشین‌حساب و JSON-LD از همین‌جا می‌خوانند).
- `lib/proof.ts`: نظرات، لوگوها و اعداد واقعی مشتریان؛ تا خالی است بخش اثبات اجتماعی رندر نمی‌شود.
- `lib/analytics.ts`: رویدادهای قیف فروش به GA/Plausible/Umami فرستاده می‌شود، هر کدام که لود شده باشد.

## صفحه‌ها

`/` معرفی · `/features/` امکانات · `/pricing/` تعرفه و ماشین‌حساب · `/gps-outage/` اختلال GPS و مقایسه · `/faq/` پرسش‌ها · `/contact/` تماس · `/blog/` بلاگ.
فهرست ناوبری و sitemap از `lib/nav.ts` می‌آید؛ هر صفحه با `PageShell` (ناوبری، پاورقی، حرکت) ساخته می‌شود.

اسکرین‌شات واقعی اپ: فایل را در `public/screens/` بگذارید و در `lib/screens.ts` ثبتش کنید؛ تا آن موقع قاب آیفون یک صفحهٔ نمایشی نشان می‌دهد.
