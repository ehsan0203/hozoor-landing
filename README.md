# سایت عمومی حضوریار

صفحهٔ معرفی، بلاگ و فرم درخواست تماس. پروژه‌ای مستقل از پنل‌ها است و فقط از API عمومی
بک‌اند حضوریار استفاده می‌کند.

```bash
npm install
npm run dev        # http://localhost:3003
npm run build      # خروجی استاتیک در out/
```

برای دیپلوی، محتوای `out/` را روی هاست IIS بگذارید. تنظیمات بدون نیاز به بیلد در
`public/config.js` (و پس از دیپلوی در `config.js` روی سرور) است: آدرس API، آدرس اپ اصلی و شمارهٔ پشتیبانی.

دامنهٔ این سایت باید در `Cors:AllowedOrigins` فایل `appsettings.Production.json` بک‌اند باشد،
وگرنه فرم تماس و بلاگ کار نمی‌کنند.
